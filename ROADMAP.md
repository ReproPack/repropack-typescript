# TypeScript roadmap

0. Foundation: complete docs and independent repository; no implementation claims.
1. Specification adoption: pin a reviewed core revision and implement the manifest model.
2. Native bundle operations: create/read/validate/verify/extract with bounded safe handling.
3. Conformance: pass canonical valid and invalid fixtures.
4. Interoperability: verify TypeScript↔Rust and TypeScript↔Python semantic equivalence.
5. Usability and release: SDK docs, optional CLI, CI, package validation, and audit evidence.

Each phase requires tests, security review, documentation updates, and evidence against acceptance criteria.
